# 角色设定集：内心小动物

> 借鉴《幸福伽菜子的快乐杀手生活》的表现手法：主角内心波动时，屏幕上弹出对应的谐音梗小动物。
> 在本产品里，五只小动物 = 排错时五种真实的内心状态。它们**外化玩家内心，不是裁判**。
> 本文档是角色与触发规则的权威定义；实现层对应 `app/utils/mascot.ts` 与 `app/components/mascot.uvue`。

## 0. 世界观

它们住在每一个程序员的脑子里，平时不说话，只在排错的特定时刻冒出来，替你说出心里那句话。
带一点冷面幽默：它们吐槽的是**处境**，永远不评判**能力**。

## 1. 五位成员

### 恐怖蛙 🐸（kowai × 蛙）

- **认知状态**：报错恐慌——屏幕上红色刷屏的瞬间，理性下线
- **性格**：胆小、一惊一乍、看见红色就炸毛
- **口癖**："呱——好多红色！完了完了要背锅了！"
- **触发**：进入故障现场时（symptoms 含 error 类证据，每关最多 1 次）
- **复盘标注**：「这一步恐怖蛙附体了。它说得对，情况确实糟——但恐慌不产生信息。」

### 不行蜗 🐌（"不行" × 蜗牛）

- **认知状态**：盲扫——没有假设的乱试，花 ⚡ 却买不到证据
- **性格**：慢性子，摇头慢半拍，但摇头摇得很坚决
- **口癖**："（慢慢探出头）……这两个动作，好像啥也没查出来。"
- **触发**：连续 2 次 `gain = low/none` 的动作
- **复盘标注**：「不行蜗在这里爬过。你在用 ⚡ 换运气，不是换信息。」

### 惊讶濑 🦦（"纳尼" × 水獭）

- **认知状态**：意外时刻——证据颠覆预期。**全场唯一奖励型出场**
- **性格**：机灵、捧场、专门负责在反转时刻弹出来尖叫
- **口癖**："纳尼？！证据它自己说话了！"
- **触发**：拿到 `gain = high` 的证据（冷却：连续 2 个动作内不重复出场）
- **复盘标注**：「惊讶濑出现的次数 = 你读到关键证据的次数。意外 = 信息。」

### 垂耳兔 🐰（垂耳 = 拒绝/摇头）

- **认知状态**：过早锁定——证据不够就想交卷（premature closure，医学里最贵的错误）
- **性格**：温和但立场坚定，用长耳朵捂住你的提交按钮
- **口癖**："（摇头）证据还不够，你只是想结束它。"
- **触发**：错误指认根因时
- **复盘标注**：「垂耳兔在这里拦了你，但你还是交了。别急——咬合的证据链比答案本身值钱。」

### 三角龙 🦖（头角 = 顶住挫败感）

- **认知状态**：挫败陪伴——连错、预算耗尽、卡住的时刻
- **性格**：沉默、稳、蹲在你旁边不动。**全场唯一只暖不刺的角色**
- **口癖**："（蹲下）这题是真难。坐一会儿，再看看现场。"
- **触发**：两次错误指认出局时 / 当前花费超过 expertCost × 2.5 时（每关最多 1 次）
- **复盘标注**：「三角龙陪了你一会儿。挫败是排错的一部分，高手不是没有挫败，是挫败后还愿意回现场。」

## 2. 语气总规则（文案作者与 AI 生成共用）

1. **先共情，再说事**：动物第一句永远替玩家说心里话（"完了完了"），吐槽只针对处境
2. **冷面吐槽为主调**；三角龙出场（挫败时刻）**只暖不刺**，绝不夹带任何"但是"
3. **永不羞辱能力**：不说"你不会""你太菜"，只说"这一步买不到信息""证据还不够"
4. **每只动物台词固定 3~5 句**，同一场次不重复；口癖词保留（呱—/纳尼？！/……）
5. 长度：台词 ≤ 20 字，复盘标注 ≤ 40 字

## 3. 引擎触发规则摘要（详见 app/utils/mascot.ts）

| 动物 | 事件 | 冷却 |
|---|---|---|
| 恐怖蛙 | 现场打开 | 每关 1 次 |
| 不行蜗 | 连续 2 次低增益动作 | 出场后计数清零 |
| 惊讶濑 | 高增益证据到手 | 2 个动作内不重复 |
| 垂耳兔 | 错误指认 | 每次触发 |
| 三角龙 | 出局 / 花费超 2.5×专家 | 每关 1 次 |

触发逻辑全部在引擎层，**案例作者零负担**（不需要为动物写任何内容）。

## 4. 图鉴（长线）

- MVP：出场计数 + 图鉴点亮（storage 持久化）
- 二期：「正确克服某偏误 N 次 → 解锁成就」（如"垂耳兔认可了你"）
- 扩员规则：新动物 = 谐音梗命名 + 一种认知状态，例如"嘴硬鲤（不承认自己看错日志）"、"躺平鸭（过早放弃直接上报）"

## 5. 换皮约定

现阶段 emoji + CSS 动画（探头/摇头/弹跳）。资产与动画规范放 `design/mascots/`，
应用层只依赖 `mascotId / emoji / line` 抽象，换皮不动触发逻辑与文案。
