# 006 · 独立管理端与监控

日期：2026-10-15 · 状态：已实施（v2）

## 决策

| 议题 | 决策 | 与 003 的关系 |
|---|---|---|
| 管理端形态 | **独立工程 `admin/`**（Vite + Vue3 + TS + Naive UI SPA），构建产物打进 api 镜像由 FastAPI 托管 `/admin/` | 推翻 003"做进 Nuxt 站 /admin，不建独立工程"的形态决策；003 的内容飞轮流程决策继续有效 |
| 鉴权 | Bearer JWT（复用 `/api/auth/login` 的响应体 token），全局路由守卫；不与社区站共享 cookie 域 | 演进 |
| 监控路线 | **混合**：可用性/错误告警用免费 SaaS（UptimeRobot 拨测 + Sentry 错误追踪），业务指标与资源水位自建落库进管理端看板 | 新增 |
| 本机时序栈 | 2G 内存服务器**不跑** Prometheus/Grafana；将来需要标准时序用 remote_write 接 Grafana Cloud | 新增 |
| 完关率口径 | v1 = 有进度用户的 solved 总数 ÷（有进度用户数 × 已上线案例数），章节级细分待 App 端进度结构对齐 | 新增 |

## 能力清单（v2 落地）

- 内容管理：投稿审核（通过/驳回/AI 预填/转草稿）、Case 编辑/元数据/发布、重建 AI 索引
- 用户管理（admin 专属）：列表搜索/改角色（防自改）/封禁解封（封禁即时生效于所有请求与三种登录入口）
- AI 用量与成本：ai_usage 台账（token/耗时/成败）+ 按日/按用户看板 + 单价 env 校准——005 P2 配额产品化的数据地基
- 运营看板：DAU/窗口活跃/新增用户趋势/投稿采纳率/完关率；活跃打点 = 登录（三种入口）+ 进度上传
- 服务健康：进程计数 + 5 分钟快照（请求/错误/耗时/RSS/磁盘，保留 30 天）+ compose healthcheck + 健康页
