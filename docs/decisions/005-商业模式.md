# 005 · 商业模式规划

日期：2026-10-13 · 状态：规划定纲（本篇定方向与路线，非实现承诺；落地前需按开放问题逐项复核）

## 决策与边界

| 议题 | 决策 | 理由 |
|---|---|---|
| 主形态 | **全内容免费 + AI 教练增值 + IP 情绪价值**（多邻国 Super 模式变体） | 内容免费做大盘子与口碑；付费买"体验与服务"，不买"通行权" |
| 内容付费墙 | **不做**（全 132 关 + UGC 增量永久免费） | 付费墙 = "卖课"心智，与"玩游戏"的产品气质冲突；内容是获客引擎不是库存 |
| 虚拟货币/商城 | 不做（继承 ROADMAP 不做清单） | 代币系统伤调性且引入合规重量 |
| 关卡内变现 | **零打断** | 付费触点只出现在"想要更多 AI 帮助"与"喜欢这个世界"两个自然位置 |
| 卖什么 | 服务（AI 教练算力）与情绪价值（IP 表达），**不卖免于挫败** | 品牌信条"思维优先"：失败是教学手段，不能被金钱消解 |

## 三条收入线

### ① AI 排错教练（主收入线）

唯一的真金边际成本服务（DeepSeek 按量计费），付费理由天然——"AI 服务要花钱"，与卖课无关。

| 档位 | 内容 | 建议定价（上线前做定价调研） |
|---|---|---|
| 免费额度 | 每日 N 次排错对话（N 待定，建议 3~5） | ¥0 |
| 加油包 | 一次性 +100 次，不清零 | ¥6 档 |
| 教练月卡 | 当月不限量（公平使用上限兜底）+ 高级复盘解读 | ¥12~18/月 |

### ② IP 情绪价值（辅收入线）

五兽（恐怖蛙/不行蜗/惊讶獭/垂耳兔/三角龙）+「好多星」品牌是已沉淀的 IP 资产（见 004）。

- 五兽皮肤与配色主题、侦探名牌/称号框、复盘室主题
- 支持者徽章（赞助制，任意金额，展示在个人档案）
- 定价 ¥6~12/件；原则：只做表达层装饰，**绝不影响判分、解锁与内容**

### ③ B2B 企业版（远期起点，不在近期承诺）

企业新员工培训 / 招聘测评——复用案例库与判分体系，客单价高；启动前置条件见拓展路线阶段三。

## 闭环链路（本模式的核心）

```
免费内容（132 关，完整自洽）
   ↓ 破案 → 复盘 → 检查单（学习闭环建立信任）
情绪兽 / 复盘仪式 /「怪不得」时刻
   ↓ 情绪依恋 = IP 依恋
AI 排错教练 ——「学不会的关」深需求 ——→ 付费①（配额）
五兽皮肤 / 名牌 / 支持者 ——「我喜欢这个世界」——→ 付费②（表达）
   ↓
UGC 投稿飞轮（投稿→AI 起草→审核→发布）
   ↓ 内容量涨 → 免费玩家获益 → 产品口碑
海报 / 称号 / 破案战绩分享 ——→ 新玩家进入
```

关键咬合：**UGC 反哺免费内容**让"免费"可持续（内容成本随社区摊薄），免费盘子越大，AI 配额与 IP 付费的基数越大——闭环成立的前提是第①条线有真成本、第②条线有真依恋。

## AI 教练成本测算（量级估算，以当期官价为准）

- 单次排错对话 ≈ 2~3k 输入 + 0.5k 输出 tokens；按 deepseek-chat 公开价量级折算 **单次成本在分钱以下**
- 免费额度 5 次/日 → 单活跃用户日成本 < 5 分；1000 DAU → 月成本数百元级
- 结论：免费额度是可承受的获客成本；月卡定价 10 倍以上覆盖重度用户成本；随用量增长在服务端加每用户日上限兜底（现有每分钟 10 次限速之上再加配额层）

## 后期拓展路线（三阶段）

### 阶段一 · 站稳（当前）

H5 单端 + 132 关 + 失败机制上线（错案重练/证据门/未破留痕）。目标：验证核心循环的留存。

**进入阶段二的门槛**：周活跃破案用户数（PRD 北极星）连续稳定，次周留存达标（具体基线在运营数据出来后回填本节）。

### 阶段二 · 做深（增长期）

| 方向 | 内容 | 依赖前置 |
|---|---|---|
| 内容扩域 | Web 后端 → 移动端/数据层/AI 应用运维新域，16 章骨架 → 30+ 章（沿用出题总纲六维难度体系） | 案例写作 SOP（已有）+ 审核产能 |
| AI 出题管线 | 投稿→AI 起草→审核飞轮升级为半自动量产；按玩家错案数据自适应推题 | 错案数据沉淀（本次失败机制已埋点） |
| 多端平台 | uni-app x 一码多端：微信小程序（拉新）+ iOS/Android 原生（留存 + IAP 通道） | 小程序主体资质；苹果开发者账号 |
| 变现动作 | AI 教练配额计费上线（免费额度→加油包/月卡）；皮肤/支持者通道打开 | 支付渠道 + 短信合规（见分期） |
| 人群扩展 | 个人开发者 → 计算机专业学生（校招季"面试排错特训"运营场景） | 内容量与高校触达渠道 |

### 阶段三 · 做宽（生态期）

- **产品线延伸**：诊断训练 → 面试实战训练（场景题/系统排错面试）→ 系统设计训练场；同一引擎换皮肤（命名已预留：诊断/侦探/值班只是皮肤，见 004）
- **B2B 启动**：企业团队版（培训/测评），私有化或 SaaS 计费
- **认证体系**：侦探等级 → 能力认证，与社区身份/简历挂钩，反哺活跃与 UGC
- **创作者经济**：投稿分成/企业定制内容/付费专栏（依赖已就位的支付基建）
- **出海**：案例英文化 → 全球 DevOps 社区；中文验证过的玩法模型直接复用

## 开放问题

- [ ] 收款主体资质（营业执照/个体户）——决定微信支付/支付宝能否接入，P2 硬前置

- [ ] 皮肤产能：五兽皮肤的美术量产节奏
