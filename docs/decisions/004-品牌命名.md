# 004 · 品牌命名定稿

日期：2026-10-03 · 状态：已定（商标待核）

## 决策

| 议题 | 决策 | 理由 |
|---|---|---|
| 中文名 | **好多星** | 感叹词式命名，不描述功能（间接性）；「多·星」骨架来自多邻国致敬与用户拍板，口语天然通顺，多抓鱼式独立产品气质 |
| 英文名 | **HowDuoThink**（展示可分写 How Duo Think） | 与「好多星」音节一一对应的谐音转写：How≈好、Duo≈多、Think≈星——多邻国式音义双关反着玩（Duolingo→邻国谐音 lingo）；名字自带问题 "how do (they) think"，App 即答案；Duo 呼应多邻国吉祥物命名传统 |
| 口号 | **多想，多星。** / **How to think.** | 名字玩谐音，口号说人话——英文口号就是产品的终极命题本身；与信条「多想一步」同源 |
| 命名原则 | 名字不说破，slogan 点破 | 功能词直接入名（想/思/脑）会显得说教且限制皮肤演进 |
| 星的机制化 | 关卡三星评价；思维仓库攒 star（GitHub 文化）；五兽点亮星座图（兽谱 → 星图） | 名字的"星"落进玩法，可收集、可炫耀 |
| 图鉴名 | **兽谱** | 借故宫《兽谱》文脉；无同名 App |
| 顿悟时刻 | 复盘中证据反转的一瞬称为「**怪不得**时刻」 | 命名讨论的高人气遗留词，进产品语言 |
| 最高段位 | 用户登顶称号为「**智多星**」 | 民间对聪明人的爱称；当称号比当品牌名合适（该词已被用友 RPA 等多个软件产品占用） |
