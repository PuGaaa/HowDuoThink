# 002 · 交互与视觉定稿（v2）

日期：2026-09-27 · 状态：已实施

## 交互定稿

- **闯关页 = FAB + 90vh 底部抽屉**：一个抽屉、三个 tab 横切（假设板 / 验证动作 / 指认根因），高度固定 90vh；FAB 常驻悬浮（z 98）作为抽屉开关，随阶段变形（立假设 → 开查 · 已花 N⚡），抽屉打开时变"收起"并隐藏。
- **假设-验证绑定关系**：动作带 `tests: [假设id]` 字段，验证 tab 按已选假设分节展示各自绑定的动作（其余完全隐藏），通用侦查类动作（tests 空）单独一节对所有人可见。假设效应标注 `hypotheses: [{id, status}]` 静默记账，**只在复盘揭晓**（终局假设板 vs 真相）——避免"看灯亮点点点"替代思考。
- **指认失败 → 返回重新假设**：垂耳兔引导面板（回假设板 / 再看证据）；假设板在验证阶段随时可编辑，"重新假设"记入心理回放。
- **导航**：全部页面 `navigationStyle: custom`；悬浮玻璃胶囊返回键（含状态栏避让与无栈兜底）+ 内容大标题；tab 页用浮动 Dock（冒险/手册/我的）。

## 视觉定稿

- **多邻国式"实体积木"硬边**：0 模糊实色投影，底部一条同色系深一号的厚度（白卡 #EFE5D6 / 珊瑚系 #F3CFA9·#E06B38 / 深墨卡 #37323F / 证据卡各自底色深一号）；三级海拔 = 页面 → 卡片 → 悬浮元素。
- **证据卡统一排版、背景色区分类型**：同字号同字体，报错浅红 / 日志浅黄 / 代码浅薄荷 / 反馈浅蓝 / 时间线浅紫灰，配同色系图标。
- **吉祥物**：生图 3D 形象（用户出图 → 洗背景 → 圆形徽章 4 档），几何 mark 为 16px 以下兜底；自有图标库 22 个（resvg 透明渲染）。
