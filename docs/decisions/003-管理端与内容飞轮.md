# 003 · 管理端与内容飞轮

日期：2026-09-27 · 状态：已实施（v1）

## 决策

| 议题 | 决策 |
|---|---|
| 管理端形态 | 做进 Nuxt 站 `/admin`（role=editor/admin 可见），不建独立工程 |
| 投稿审核 | 列表（全状态）→ 展开全文 → 通过并生成 Case 草稿 / 驳回（带备注） |
| 草稿生成 | 从投稿字段启发式映射：title/symptom/key_error → 症状面，resolution 按句拆专家链骨架，lessons → 检查单；重字段填"（待补充）"占位，编辑器计数提示 |
| Case 编辑 | JSON 编辑器直编 + 保存草稿（无门禁）/ 发布（Pydantic + gate.py 红线）|
| 认证 | JWT cookie；dev 绕行登录 login=admin* 自动 editor/admin（生产配置 GITHUB_ADMIN_LOGINS）|

## 内容飞轮

```
用户投稿（Web 表单）→ 管理端审核 → 生成草稿 → 编辑器补齐创作性字段
   → 发布（门禁+version 递增+文章投影）→ Web 展示 + App casepack 拉取
```

## 已知注意点

- Pydantic v2 的 `Cookie | None` 简写 union 在 Py3.13 会运行时 TypeError——统一用 `Annotated[str | None, Cookie()]`
- FastAPI 参数顺序：有默认值的 Cookie 参数放前面会导致语法错误，status 这类 query 参数声明在 uid 之前
- 修改 FastAPI 代码必须确认进程重启成功（端口占用时旧进程存活，会造成"改了没生效"）
