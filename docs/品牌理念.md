# Debugo 品牌理念 v1

> Debugo 暂为项目代号。

## 一句话

Debugo 是一座住满"思维兽"的训练场——用真实故障当教材，训练工程师的思考方式。**解决问题只是过程，思维晋升才是结果。**

## 核心信条

1. **思维优先于知识**：训练的不是知识点，而是高手的核心习惯。
2. **真实问题当教材**：每个案例都来自真实世界；脱离真实场景的刷题不产生思维。
3. **情绪是认知的一部分**：恐慌、惊讶、沮丧、迟疑值得被外化、被看见、被驯服——五兽就是五种排错情绪。
4. **过程与结果**：解决问题是过程，带走思考方式（检查单）才是结果。

## 思维体系 · 四层十一思

### 视野层 —— 看得全

- **全栈视野**：接入/构建/数据/运行时/并发/可观测六大层——先画圈再下钻
- **产品思维**：影响面的本质是用户体验：故障对业务/用户意味着什么
- **安全思维**：证书链/鉴权/注入——每个故障都可能是安全问题的冰山一角

### 推理层 —— 想得深

- **假设思维**：候选假设集，而非瞎猜
- **成本思维**：按验证成本排序，最小代价定位
- **验证思维**：证据说话，实锤再指认

### 设计层 —— 追得远

- **架构设计思维**：故障的种子是设计取舍：缓存窗口、重试风暴、超时级联、幂等缺失——根因常在设计时种下
- **程序设计思维**：代码边界/状态管理/防御式编程——让故障无从发生

### 沉淀层 —— 留得下

- **复盘思维**：检查单 = 把经验变成防御
- **拓展知识**：层契约知识（TLS 握手/索引原理/协议行为）——每关带走一条

## 品牌人格

聪明但不装、可爱但不幼稚；五兽是伙伴不是道具；语言说人话、有幽默感、尊重智商。

## 皮肤与内核的边界

**诊断/侦探/值班 = 皮肤**（关卡表现形式，会演进）；**思维训练 = 内核**（不变）。品牌命名与文案锚定内核，不锚定皮肤。
