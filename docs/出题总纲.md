- 50 关时：每思 ≥5 关**专属载体**（主训标注）。

## 三、关卡规格 · 出题八件套

每关立项必填（写进案例文件头注释 + 提案表）：

1. **主训思维**（四层十一思之一，标注到"层-思"）
2. **次训思维**（1~2 项）
3. **真实故障原型**（业界真实事件/内部工单，禁止虚构无原型题）
4. **皮肤**（排查现场 / 评审现场 / 决策现场——皮肤可演进，内核不变）
5. **情绪兽出场设计**（哪个节点、哪只兽、点什么情绪）
6. **检查单预告**（思维型 ≥3、知识型 ≤1）
7. **危险动作**（L≥2 必须含回滚/状态变更类，1 个教学陷阱）
8. **层契约**（一句话，沉淀为手册条目）

## 四、难度曲线（每章模板）

L1 入门 ×1~2（apprentice）→ L2 标准 ×2~4（engineer）→ L3 困难 ×2~3（master）→ 结业评审 L3 ×1（评审现场皮肤）。
解锁按篇独立：篇门（前一篇每章破 ≥1 解锁下一篇）→ 篇内序贯（前章破 ≥1 解锁本章，篇首章随篇直开）+ 跳级挑战（本章首关恒可玩）。
