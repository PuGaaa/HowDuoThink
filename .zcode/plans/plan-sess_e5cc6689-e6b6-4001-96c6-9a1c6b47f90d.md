# App 登录接入（账密 + Bearer token）

## 方案要点
传输方式选 **token 而非 cookie**：uni-app x 将来编译原生端时 cookie 行为不可控，H5 跨域 cookie 又要 withCredentials；改为后端登录时返回 token，App 存 storage 后续带 `Authorization: Bearer`，H5/Web 的 cookie 路径保持不动——两端各走各的通道，互不影响。
登录方式 v0 只做**账密登录**（GitHub OAuth 需要跳转回调域，App 端暂不适用；账号来源 = 管理员种子 + Web 端 GitHub 注册）。

## 改动清单

### 后端（小改）
1. `features/auth/service.py` 新增 `login_payload()` 或直接在路由响应里带 `token`
2. `features/auth/router.py`：`/api/auth/login` 响应体加 `token` 字段（cookie 照设，Web 不受影响）
3. `core/deps.py`：`current_user` 支持 `Authorization: Bearer <jwt>` 头（优先 cookie，回退 Bearer）
4. `tests/test_auth.py` 加用例：登录拿 token → Bearer 头调 /api/me 200

### App 端
5. `app/utils/auth.ts` 新增：token/user 存 storage（`think_token`/`think_user`）、login()、logout()、fetchMe()（uni.request 带 Bearer）
6. 新页面 `app/pages/login/login.uvue`：navbar 返回 + 白卡表单（账号/密码）+ 珊瑚主按钮（含硬边阴影缓冲，遵守容器规则）+ 提示"账号由团队发放或 Web 端 GitHub 注册"；登录成功存 token/user 后 navigateBack
7. `app/pages.json` 注册 login 页
8. `app/pages/profile/profile.uvue` 账号卡两态：未登录 → 「去登录」按钮跳登录页；已登录 → 头像 + 昵称 + 角色 + 「退出登录」（清 storage）；refresh() 读取本地 user 态

### 验收
- pytest 全绿（含新 Bearer 用例）
- 浏览器走查：未登录 profile → 登录页 → admin 登录 → 返回显示账号信息 → 退出登录恢复未登录态
- Web 端回归：cookie 登录不受影响
- git 提交

## 不做
GitHub OAuth 的 App 端跳转；进度多端同步接口（后端尚无该 API，登录 v0 只解决身份）；注册功能（后端无注册端点，文案改为"账号由团队发放"）。
