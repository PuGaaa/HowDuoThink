# Figma 可爱风设计轮 — 实施计划

## 〇、桥接准备（需要你 10 秒）

本会话早于插件安装启动，官方注入的 Figma MCP 工具我拿不到。方案：我用同款 `server.mjs` 起一个专属桥实例（端口 **3056**），你在 **Figma 桌面端插件面板把地址改为 `ws://localhost:3056` 点「连接」**即可（ZCode 原桥不受影响）。

## 一、设计定调：「一本正经的教学 × 少男少女心」

内容与文案保持严谨（教学是骨），皮肤全面软萌（可爱是皮）：

- **色板**：奶油底 `#FFF9F4`；主色珊瑚橙 `#FF8A5C`（CTA/⚡成本）；樱花粉 `#FFB5C2`（章节/装饰/路径线）；薄荷 `#6FCFB2`（成功/已执行✓）；天空蓝 `#7EC8E3`（信息/层标签）；柠檬黄 `#FFD66B`（星星/🔥）；正文暖紫灰 `#4A4458`
- **形状**：大圆角（卡 20~24、按钮全 pill）、软描边 `#F2E4D8`、贴纸感徽章、虚线可爱路径连接线
- **反差保留一处严肃**：报错/log/code 证据卡仍是深色终端卡（底改暖黑 `#3A3440` 奶白字）——"一本正经"的部分
- **吉祥物加大出场**：问候气泡、图鉴大卡、撒花彩蛋；五只动物 emoji 是可爱风的核心资产
- 不引入版权字体，靠颜色/圆角/贴纸感传达可爱，H5 端可还原

## 二、Figma 产出流程（全自动）

1. 写 `content/tools/figma-rpc.mjs`：JSON-RPC 客户端（spawn 同款 server.mjs 于 3056，stdio 通信），之后每次 Figma 操作 = 一条命令
2. `bridge_status` 确认插件已连 → `execute_figma_code` 新建页面「排错推理训练场 · MVP」
3. **4 屏设计稿（390×844）逐屏 `create_node_from_svg` 写回**：①首页·章节路径图（含 🔥streak、称号条、灰节点）②闯关页（终端报错卡/假设板/动作清单/动物气泡/成本条）③复盘页（深墨仪式卡+三星+成本对比+下一关）④诊断手册（称号卡/动物图鉴/检查单收集）——页面规划沿用上轮已确认的 1.1~1.4（页面清单/核心循环/线框/状态）
4. **`export_node_image` 截图自查**：我亲自逐屏看图，修正间距/配色/字号后重导，至少一轮迭代
5. 关键标题文案用 `create_text` 叠加可编辑图层（SVG 文字会转轮廓）
6. 把 Figma 页面链接给你——**你在 Figma 里审稿**，改到满意为止

## 三、你审稿通过后（本轮先不做）

按 Figma 终稿落地代码：竖版 max-width 480px + 动机系统（三星/下一关/streak/称号/手册页）+ 全组件按可爱 token 重刷 + 浏览器实测 + 视觉验收。`design/ui-spec.md` 归档（页面规划 + tokens + 组件规格）。
