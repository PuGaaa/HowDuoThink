# 任务系统 + 分享海报 + 手册降级 — 最终规划

## 一、Tab 调整

- Tabbar：**冒险 / 任务 / 我的**（手册 tab 移除）
- 手册降级为「我的」页入口行（资料卡下“我的手册 →”），顶部补返回键
- 手册内检查单**可编辑**：改文案存 storage 覆盖默认（用户笔记优先，可恢复）

## 二、任务系统（三类，进度全用已有埋点）

| 类型 | 刷新 | 任务例 |
|---|---|---|
| 每日 | 0 点重置 | 今日首胜 / 核对检查单 1 次 / 立假设 ≥2 |
| 每周 | 周一 | 破案 3 关 / 集齐 2 层检查单 |
| 成长 | 永久 | 称号晋升 / 全章通关 |

数据：`tasks.ts` 定义 + storage `{date, progress}` 跨天重置；进度源 = saveSession / bumpChecklistUse / 假设事件计数（全部已有埋点）。

**任务页**（task.uvue）：今日进度环 + 每日任务列表（进度条+勾）+ 每周折叠 + 成长称号进度。

## 三、任务积累可展示（新增，两条腿）

### 1. 可爱分享海报（post.uvue，Canvas 绘制）

- 「侦探档案卡」风格，与积木视觉同源：奶油底 + 三色积木装饰条 + 吉祥物头像图（static 资产）
- 内容：称号 + 破案数 / 检查单数 / 连续天数 / 最低成本 + 篇进度条 + 底部 slogan
- 数据全部来自已有 getter（rankOf/getTotals/getStreak/getChecklistUse），零新埋点
- 交互：任务页与我的页「生成分享海报」按钮 → Canvas 绘制 → **H5 下载 PNG**（App 端后续 saveImageToPhotos）
- 生成后可保存，随任务积累数据自动更新——每次数据变化，海报就是新的

### 2. 好友系统预留（数据设计，v1 不做好友功能）

- 新增纯函数 `getProfileSnapshot()`：把任务/成就数据序列化为**可展示 profile 结构**（name/rank/streak/solved/lessons/partProgress）——这就是未来好友查看你主页的完整数据源
- 后端 v2 加 `GET /api/users/:login/profile` 时直接复用此结构
- v1 的落地形式：海报即“个人名片”，分享行为就是好友系统的种子

## 四、实施批次

**T1 任务系统核心**：tasks.ts + storage 进度（跨天重置）+ task.uvue + tabbar（冒险/任务/我的）
**T2 分享海报**：post.uvue Canvas 绘制 + 下载 PNG + 任务页/我的页入口
**T3 手册降级 + 检查单可编辑**：tabbar 移除手册 → 我的页入口行 + 手册返回键 + 每条检查单可编辑（storage 覆盖，可恢复）
**T4 验证**：任务随真实行为推进 + 海报生成下载 + 手册编辑 + 截图验收

## 五、不做

## 六、验证

任务进度随破案/核对/立假设真实推进；海报 PNG 可下载且数据正确；手册编辑保存/恢复默认；tab 三项切换正常；全流程截图验收。
