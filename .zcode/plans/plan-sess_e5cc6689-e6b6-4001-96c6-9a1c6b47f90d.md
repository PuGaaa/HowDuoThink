# server/ 重构为 Feature 架构

## 目标结构

```
server/
├── main.py                  # app 工厂：create_app() + 挂路由 + 启动种子（不再有 import 副作用）
├── core/                    # 横切关注点，任何 feature 可 import
│   ├── config.py            # 环境变量集中（CLIENT_ID/JWT_SECRET/ADMIN_PASSWORD/WEB_ORIGIN/DEV_MODE/COOKIE_SECURE）
│   ├── db.py                # 现有 q/ex/tx/jdump/jload + init()
│   ├── security.py          # bcrypt 哈希/校验/升级 + JWT 签发/校验（从 oauth_github.py 拆出）
│   └── deps.py              # current_user / require_editor（从 main.py 拆出）
├── features/
│   ├── auth/                # router(登录/OAuth回调/dev绕行/me/密码) + service(现service_auth) + oauth.py(GitHub客户端) + models.py
│   ├── cases/               # router(发布/admin cases/meta) + service + gate(现gate.py) + models(CasePayload等) 
│   ├── submissions/         # router(投稿/我的投稿/审核状态/draft) + service(投稿→草稿骨架) + models
│   ├── solutions/           # router(solutions 列表/详情) + article_view
│   └── sync/                # router(casepack) —— 经 cases 的 service 公开接口取数据
├── seed.py / test_main.py   # 保留；测试按 feature 拆为 tests/（test_auth/test_cases/test_sync）
```

## 依赖规则（写进 core/README 或模块 docstring）

- feature → core：允许
- feature → 其他 feature 的 service：仅限 cases.service（供 submissions 转稿、sync 拉取使用）；反向禁止
- 任何 SQL 迁入各 feature 的 service/repo；路由层只剩 参数→service→响应

## 迁移步骤（每步后 pytest 11 个用例必须全绿）

1. 建 core/：config 从 oauth_github 拆环境变量；security 拆哈希+JWT；deps 从 main 拆鉴权依赖
2. 建 features/auth：搬登录/OAuth/dev/me/密码 5 个路由 + service_auth + oauth 客户端
3. 建 features/cases：搬发布/admin cases/meta 路由 + service_case + gate + CasePayload 模型；**顺带把残留读路径 SQL（admin 列表/详情）也沉到 service**，补齐上半场没做完的分层
4. 建 features/submissions：投稿/审核/draft 路由 + 转稿 service
5. 建 features/solutions + features/sync：只读路由迁移
6. main.py 收敛为 app 工厂（create_app），消除 import 副作用，测试改用 create_app() 
7. test_main.py 拆为 tests/ 目录按域对齐；全量回归 + 浏览器/App 端冒烟（登录、发布、casepack 同步）

## 不做

- 不换 SQLite、不引 ORM（db.py 薄封装继续用）；不一次抽完美 repository（随功能演进）；admin 不单独成 feature（编排职责分散在 cases/submissions 的 admin 路由里，避免循环依赖）

## 验收

pytest 全绿；`/docs` 接口行为与重构前一致（同路径同方法同返回）；App 三端（H5/Web/后端）联调冒烟通过；README 仓库地图更新目录说明
