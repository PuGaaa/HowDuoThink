# 个人信息主次翻转 + 资料编辑（昵称/头像）

## 设计要点
- **主次翻转**：档案卡大头像 = 个人头像（用户头像 → 默认白猫），主文字 = 昵称；称号降为昵称下方的**金色胶囊徽章**（次级），meta/进度条保留。frog 吉祥物撤出头像位，改为头像右下角的**小徽章点缀**（可爱保留、不抢主位）
- **默认昵称**：后端手机号建号时自动生成可爱代号（形容词池 × 动物池，如「敏锐的小海豚」「机警的小柴」），编辑页可随时改；GitHub 用户用 GitHub 名
- **首页头像**：header 头像 = 用户头像（user.avatar → 本地预设 → 默认白猫），frog 退位
- **头像编辑方案**：v0 无文件上传，采用**预设头像六选一**（5 吉祥物 + 白猫），选中即本地生效（storage）；将来接上传后存 URL 走同一字段
