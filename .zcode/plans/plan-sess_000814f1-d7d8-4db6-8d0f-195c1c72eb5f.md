## 任务一：通关失败机制（代码实现，同上版不变）

- **证据门（全篇）**：未做任何验证动作不许指认（toast 引导，不扣机会）——顺着"先假设→再验证"的自然流向 nudge
- **失败留痕**：`CaseProgress`+`fails`；章节地图"未破"警示标，点击重练
- **streak 修正**：仅破案计连续天数
- **失败终局页**：victory 分流"本案未破"+ 三角龙/垂耳兔安慰 + "再战一局"
- **错案重练任务**：曾失败关破案 → 每日任务 `retrain` +1

改动文件：`scoring.ts`（常量 MAX_WRONG_IDENTIFIES=2）、`play.uvue`（证据门+文案）、`storage.ts`（fails/埋点/streak 分支）、`sync-progress.ts`（fails 取 max）、`victory.uvue`（失败态）、`chapter.uvue`（未破标）、`tasks.ts`（+1 任务）、server `progress/models.py`（+fails 字段）、`test_progress.py`（样例+断言）、`docs/PRD.md`（规则更新）。

验收：①零验证不能指认且不扣机会 ②2 次出局不变 ③失败页无"破案成功"字样、可直达重玩 ④失败不续 streak、地图留痕、云同步含 fails ⑤重练破案任务计数+1。

## 任务二：商业模式规划（`docs/decisions/005-商业模式.md`）

### 主形态：全内容免费 + AI 教练增值 + IP 情绪价值（多邻国 Super 变体）
1. **边界**：不做虚拟货币/商城（继承 ROADMAP）；不做内容付费墙（不卖课）；关卡内零打断
2. **收入线**：①AI 排错教练配额（主，唯一真金成本服务，免费额度+加油包/月卡，附成本测算与定价建议）②情绪兽皮肤/侦探名牌/支持者徽章（辅，自愿低客单，呼应 004 IP 资产）③B2B（远期起点）
3. **闭环链路**：免费内容做大活跃 → 情绪兽/复盘建立 IP 依恋 → AI 教练承接"学不会"（付费①）→ 皮肤徽章表达身份（付费②）→ UGC 飞轮反哺内容 → 海报/称号传播 → 新玩家

### 后期拓展路线（本次新增的核心章节）
**阶段一 · 站稳（当前）**：H5 单端 + 132 关打磨 + 失败机制上线。进入下一阶段的门槛：周活跃破案用户稳定、次周留存达标（PRD 北极星）。

**阶段二 · 做深（增长期）**：
- **内容扩域**：Web 后端 → 移动端/数据层/AI 应用运维等新域（16 章骨架 → 30+ 章，沿用出题总纲六维难度体系）
- **AI 出题管线**：投稿→AI 起草→审核飞轮升级为半自动量产 + 按玩家弱项自适应推题
- **多端平台**：uni-app x 一码多端——微信小程序（拉新入口）+ iOS/Android 原生（留存+IAP 通道）
- **变现动作**：AI 教练配额计费上线；皮肤/支持者通道打开
- **人群扩展**：个人开发者 → 计算机专业学生（校招季"面试排错特训"场景）

**阶段三 · 做宽（生态期）**：
- **产品线延伸**：诊断训练 → 面试实战训练（场景题/系统排错面试）→ 系统设计训练场
- **B2B 启动**：企业团队版（新员工培训/招聘测评），客单价高、复用现有案例库与判分体系
- **认证体系**：侦探等级 → 能力认证（与社区身份/简历挂钩，反哺 UGC 与活跃）
- **创作者经济**：投稿分成/企业定制内容/付费专栏（依赖已就位的支付基建）
- **出海**：案例英文化 → DevOps 社区全球市场（中文验证过的玩法模型直接复用）

每阶段写明：进入条件（指标门槛）、拓展内容、变现动作、依赖的基建前置（如支付渠道、短信合规、多端工程）。
